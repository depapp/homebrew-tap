# depapp/homebrew-tap

Homebrew formulae for [depapp](https://github.com/depapp) projects.

```bash
brew install depapp/tap/sapu
```

| Formula | What | Source |
|---|---|---|
| `sapu` | Sweep your Android clean: deep clean, debloat, analyze and optimize over adb, no root | https://github.com/depapp/sapu |

`Formula/sapu.rb` is regenerated by the Sapu Release workflow on every tag; do not edit it by hand.
